# org.fuin.dsl.cqrs
Maven build of the DDD/CQRS Xtext DSL — produces the parser artifact used outside Eclipse.

[![Maven Central](https://img.shields.io/maven-central/v/org.fuin.dsl/ddd-cqrs-dsl.svg)](https://central.sonatype.com/artifact/org.fuin.dsl/ddd-cqrs-dsl)

This is the Maven counterpart of the [eclipse](../eclipse) project. The DSL grammar and generated
sources are maintained in Eclipse and mirrored here; see the top-level [README](../README.md) for the
overall layout and the workflow for changing the DSL.

The published artifact is `org.fuin.dsl:ddd-cqrs-dsl`, built from the
[org.fuin.dsl.cqrs](org.fuin.dsl.cqrs) submodule.
